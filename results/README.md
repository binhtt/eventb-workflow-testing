# Recorded data dictionary

These files are the recorded study evidence.
The supported reproduction entry point writes new results under outputs/.

| File | Contents and units |
|---|---|
| trials.csv | One row per request/capacity/method/seed/mutant; first_detection is an execution index 1–16, or blank if undetected by the cap |
| costs.csv | Generation and replay seconds per 16-schedule suite; includes objective counts |
| qualified_summary.csv | Eligible temporal detections by configuration, method and budget |
| per_mutant.csv | All mutant/configuration results, split labels and eligibility |
| paired_bootstrap.csv | Model-minus-random differences in percentage points and paired seed-cluster intervals |
| timing.csv | Timing summary derived from costs.csv |
| standalone_timing.csv | Separate timing observations in milliseconds; 30 repetitions per method/configuration |
| standalone_timing_summary.csv | Medians of the separate timing observations |
| witnesses.json | Legal scheduled hooks, persistent-state snapshots, observations and latched failures |
| model_conformance.json | Complete finite-state counts, accepted/rejected attempts and local elapsed seconds |
| extracted_objectives.json | XML guards, guard/action variable sets and extracted objectives for four requests |
| proof_bridge.json | Core/proof model equivalence, suite counts and deterministic schedule digest |
| proof_normalization.json | Proof-only definition/theorem normalization audit |
| run_summary.json | Main experiment settings, counts, original software environment and model hash |
| environment.json | CPU/container, Python and SQLite details |
| summary.md | Human-readable tables generated by analyse.py |
| progress.log | Completion output from the main experiment |
| model_conformance.log | Original finite conformance output |
| timing_progress.log | Original standalone timing output |

Seeds are paired across methods and reused across configurations.
A blank first_detection is right-censoring at the 16-execution cap.
It must not be silently interpreted as detection on execution sixteen.

Generation time includes objective extraction and feasible-prefix construction.
Replay time in costs.csv includes the reference and all nine mutants.
The separate clean timing table measures reference replay with conformance.

The main trial table has 5,400 rows.
The cost table has 600 rows.
There are nine mutants, four methods, 50 seeds and three configurations.
The qualified temporal denominator is 550 trials per method.

The data describe four qualified evaluation mutants, rather than 550
independent faults. All six reserved evaluation mutants remain in the raw
data, including two detected at nominal execution and the inactive
capacity-one mutation branch.
